WHY BALLAST

Free. Simple. Serverless. Permissionless. No external dependencies.
Runnable in 30 years. It should outlast some rails.

FREE
No licence, no seat count, no renewal, no vendor to call. Copy the file
and you have another installation.

SIMPLE
One HTML file, about 120 KB, in plain JavaScript that a person can read
end to end. Three roles, eight kinds of file, one job: issue a test,
write it, mark it, prove the marks. Nothing is configured; nothing is
administered.

SERVERLESS
Nothing runs anywhere except in the browser in front of you. There is no
account, no database, no service to keep up, no log on someone else's
machine. The files are the network: registrations, tests, releases and
marks are small text files that move however your files already move --
a shared drive, an email, a Teams message, a USB stick, paper.

PERMISSIONLESS
No installer, no administrator rights, no open port, no firewall
exception. It runs from a shared drive, from a website, or from a file on
a desktop. Nothing it does needs to be allowed by anyone, because nothing
it does looks different from opening a web page and saving a text file.
The page's own policy forbids it from talking to the network at all.

NO EXTERNAL DEPENDENCIES
No framework, no package, no CDN, no font server, no update channel. The
cryptography is the browser's own WebCrypto -- the same AES-GCM, P-256,
SHA-256, HKDF and PBKDF2 that TLS uses. Every file format is written down
byte by byte in SPEC.md, and verify.py re-scores a release in Python with
no browser at all, so the app is never the only thing that can read its
own files.

RUNNABLE IN 30 YEARS
Browsers do not remove JavaScript features or WebCrypto algorithms; a
page that runs today runs in the next version. There is nothing to
expire, nothing to renew, no company whose closing takes the software
with it. Text files stay readable by anything that reads text. The whole
system is a file you can hash once, keep, and open in 2056.

WHAT IT IS NOT
It is not a proctoring system. Once a question is on a screen it is
cleartext for the person looking at it, and no software can stop them
reading, remembering or photographing it. What Ballast does is keep the
answers out of the file, show one item at a time under fullscreen with
the keyboard locked, refuse copy and print, record every break, watermark
every frame with the writer's name, and sign everything that moves so
that a mark can always be traced back to the answers it was given for.
