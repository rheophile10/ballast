# Samples

- `test1-definitions-signals.txt`, `test2-crossings-switches.txt`, `test3-block-c.txt` — test sources (SPEC.md §10). Drop them on an RTC desk or a superintendent's book, or paste one into Practice.
- `files/` — one of everything that moves, as armored text: a registration, minted profiles (crew, RTC, superintendent), an approval, a test file (window 1–8 Sept 2026, so it will not open now — that is the point), Alice's release, her cancellation, Denise's class profile, and Denise's sheet (passphrase `sample`; `python3 verify.py samples/files/sheet-Denise-Okafor.txt samples/test1-definitions-signals.txt samples/files/release-Alice-Marchand.txt --pass sample` re-scores the release). Regenerated by `node samples/make.mjs`.
- `cast.json` — the fictional cast the tutorial plays with: one superintendent, three RTCs, twelve crew, all with real signed mints and **their private keys** (a demo cast, not people; never reuse these keys). Regenerate with `node samples/make.mjs`.
